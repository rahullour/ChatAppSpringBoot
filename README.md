## WeChat - Created a chatting site using RAD framework Spring Boot & Firebase, for real time experience, deployed on Render .
* Tech : Java, Spring Boot, Hibernate, Spring MVC, Thymeleaf, Firebase Firestore, Cloudﬂare R2 .
